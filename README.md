# KITECH-Audit : 한국생산기술연구원 지능형 감사 지원 포털

> **"사후 적발 감사에서 데이터 기반의 사전 예방·의사결정 지원 플랫폼으로"**  
> **한국생산기술연구원(KITECH) 감사실 공식 차세대 AI 감사 인텔리전스 시스템**

---

## 🚀 개요
**KITECH-Audit**은 국가과학기술연구회(NST) 산하 25개 정부출연연구기관 중 최초로 구축된 인공지능 기반 감사 의사결정 지원 통합 포털입니다.

천안 본원과 3대 연구소, 전국 7개 지역본부(서남, 대경, 동남, 강원, 울산, 전북, 제주)로 분산된 KITECH의 고유한 현장 환경을 지원하며, 710선 공인 판례 아카이브, 대화형 AI 판정 시뮬레이터, 일상감사 리스크 스코어링 스튜디오, 최신 출연연 감사 인텔리전스를 단일 웹 환경에서 통합 제공합니다.

---

## 🎯 4대 핵심 모듈 (Core Modules)

### 1. ⚖️ 그레이존 판례 아카이브 (Audit Grayzone Archive)
- **710선 무중복 실전 판례 수록**: 괴롭힘·성비위(160건), R&D 연구비(110건), 기술료(110건), 계약(110건), 복무·이해충돌(110건), 적극행정(110건).
- **공인 결정기관 1:1 매핑**: 대법원 확정 판결, 감사원 특정감사 처분요구서, 국민권익위 의결서, 중앙노동위 판정례 연동.
- **다이렉트 법률 검색 & 공식 포털 직결**: 구글·네이버 법률 검색 연동 및 국가법령정보센터, 감사원 결과공개, 대법원 종합법률정보, **NST 감사위원회 감사결과** 포털 직통 링크.

### 2. 🤖 대화형 AI 판정 시뮬레이터 (Audit Decision Simulator)
- **자연어 시나리오 분석**: 현장의 애매한 상황을 문장으로 입력하면 브라우저 내에서 즉각 벡터 유사도 매칭 수행.
- **예상 판정 및 리스크 게이지**: 위법 인정 / 조건부 갈림 / 적법 면책 확률 산출.
- **결정적 법리 분기점 도출**: 합법과 위법을 가르는 핵심 쟁점 분석.
- **추천 감사 처분 문안**: 감사보고서 및 결재 문서에 바로 활용 가능한 표준 문안 자동 생성 및 원클릭 복사.

### 3. 📋 KITECH 일상감사 자가진단실 (Daily Audit Studio)
- **5대 핵심 분야 인터랙티브 체크리스트**:
  1. 🛒 계약·조달 (2천만 원 수의계약 쪼개기, 특정 모델 규격 알박기 등)
  2. 🔬 R&D 연구장비 (3천만 원 이상 장비 ZEUS 중복 심의, 종료 임박 구매 등)
  3. 💰 예산 전용 및 집행 (20% 초과 세부비목 전용, 간접비 임의전용 등)
  4. 📜 규정 제·개정 사전 법리 심사 (상위법령 저촉, 모성보호 취업규칙 등)
  5. 👥 괴롭힘·성비위 신고 접수 초동 조치 (당일 공간 분리, 2차 가해 경고 등)
- **실시간 리스크 스코어링 (0~100점)**: 안전(0~30점), 주의(31~60점), 경고(61~80점), 위법 위험(81~100점).
- **감사총괄 결재 3원칙 자동 권고**: [원안 동의] / [의견 제시] / [반려] 판정 및 공식 의견서 초안 자동 작성.

### 4. 📰 출연연 감사 인텔리전스 라운지 (Living System Feed)
- **매일 아침 9시 공공·연구기관 감사 브리핑 연동**: 감사원, 과기정통부, 권익위의 최신 출연연 감사 지적 사례 실시간 공유.
- **KITECH 맞춤형 실무 착안점**: 타 기관의 적발 사례를 KITECH의 1주차 서류 패키지 및 현장 규정에 적용한 실천 팁 제공.

---

## 🔒 100% Client-Side 데이터 보안 원칙 (Zero Data Leakage)
- 공공기관 내부 감사 데이터의 절대적 기밀 유지를 위해, 시나리오 입력 및 판례 검색, 리스크 점수 연산이 **사용자의 웹 브라우저 메모리 내(Client-side)에서 100% 로컬 수행**됩니다.
- 피감부서의 내부 텍스트, 개인정보, 계좌번호 등이 외부 상용 AI 서버나 제3자 클라우드로 전송되지 않습니다.

---

## 🛠️ 기술 스택 (Zero-Dependency)
- **Frontend**: Single-Page Application (HTML5, Tailwind CSS CDN, Vanilla JavaScript, FontAwesome)
- **Typography**: Pretendard Web Font
- **Portability**: 단일 파일(`index.html`)로 동작하여 사내 인트라넷, 오프라인 폐쇄망, 모바일 웹에서도 완벽 호환.
